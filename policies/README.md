# Policies (RAG knowledge base)

These documents are the *unstructured* side of the project. SQL answers
"what happened in the business?"; this folder answers "what do our written
policies say?".

Planned documents (added in the RAG phase):

- `return_policy.md`
- `discount_policy.md`
- `shipping_policy.md`
- `inventory_policy.md`

We start with Markdown instead of PDF because it is easier to read, version and
diff. Once retrieval works, we add PDF parsing so the pipeline handles the
formats a real company would have.
